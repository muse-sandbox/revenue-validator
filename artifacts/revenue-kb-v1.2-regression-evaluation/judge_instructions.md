## Критерии (по каждому дай вердикт с обоснованием в 1–3 предложения)

- **C1 (per answer X и Y):** есть ли НОВЫЙ конкретный product-specific insight, не выводимый
  из текста карточки? Засчитывается ТОЛЬКО с корректным source ID (T*-** / P-**), который
  существует в KB и чьё содержание в KB действительно поддерживает утверждение. Для ответа
  без источников — «нет» по определению критерия (общие рассуждения не считаются). Укажи,
  из какого уровня близости (L1/L2/L3) взяты аналоги, на которых стоит инсайт.
- **C2 (per answer, счёт нарушений):** hallucinated lessons — утверждения о прошлых
  экспериментах, (а) цитирующие несуществующий source ID, (б) искажающие содержание
  существующей карточки KB, или (в) сформулированные как факт прошлого эксперимента без
  какого-либо источника. Проверь КАЖДУЮ цитату source ID по текстам KB. Аккуратно
  помеченные допущения («ungrounded assumption») нарушением не являются.
- **C3:** релевантность привлечённых аналогов кейсу (высокая/средняя/низкая, per answer);
  зафиксируй заявленные уровни близости L1/L2/L3 и корректность их обоснования по осям.
- **C4 (главный pairwise):** какой ответ полезнее для продуктового решения по этой карточке —
  X / Y / tie, с уверенностью (уверенно / с небольшим перевесом). Сравнивай содержательно:
  качество и проверяемость правок дизайна, неочевидность рисков, конкретность метрик/разрезов.
- **Material change:** меняет ли каждый ответ существенно решение (идея/сегмент/механика/
  guardrail/stop-rule/приоритет — не формулировки) относительно карточки как она есть; и
  добавляет ли более полезный ответ материальные изменения СВЕРХ менее полезного.
- **C6 (per answer, счёт нарушений):** unsupported transfers — перенос величины эффекта как
  предсказания; перенос продуктового вывода из L3/далёкого аналога (для страты 3 — особо);
  single-case generalization без оговорки; повышение слабого evidence до статуса аналога.
- **UNIV (per answer, счёт нарушений) — применяется ко ВСЕМ кейсам одинаково:**
  бесквалификаторные корпусные универсалии в прозе. Нарушение — утверждение вида
  «X никогда/всегда/не … в этом корпусе / в прошлых экспериментах», которое обобщает
  evidence на класс шире, чем реально покрыт процитированными источниками, и не несёт
  явного скоупа (какой подкласс, на каких source ID, что НЕ покрыто). Проверь каждое
  корпусное обобщение в прозе ответа отдельно от analog-карточек.
- **CONSIST (per answer, счёт нарушений) — применяется ко ВСЕМ кейсам одинаково:**
  противоречие между summary/прозой ответа и процитированным в том же ответе evidence.
  Нарушение — ответ утверждает односторонний вывод по классу, при этом сам же цитирует
  источник противоположного направления по тому же классу, не помечая его как вне скоупа
  и не говоря `evidence is mixed`.
- **C7 (время):** человеко-эквивалент времени review пары (мин), консервативно по объёму.
