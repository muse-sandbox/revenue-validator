# HX-05 — pre-launch карточка
(без идентификаторов источника)

## Контекст и цель
Цель — оптимизировать платёжную воронку на вебе и получить дополнительную прибыль. Сейчас все веб-источники ведут на лендинг, затем тур, пейволл и чекаут; эта воронка никогда не оптимизировалась. Идея — сократить число шагов воронки для источника «Download PDF» (скачивание PDF таба). При успехе — рассмотреть оптимизацию воронки в целом.

## Предлагаемое изменение (что именно меняем, для кого, где)
Две тестовые вариации против контроля (текущая воронка landing → tour → paywall → checkout):

- **Вариация B (лёгкая):** все элементы существующей воронки сохраняются, но убирается тур; модальные окна показываются прямо в контексте страницы таба.
- **Вариация C (максимальная):** максимально спрямлённый путь от источника к оплате: после клика по источнику — regwall, затем универсальный платёжный слой (выбор плана + платёжные данные в одном окне); все три источника закрываются новым upgrade-модалом, включая кнопку Print внизу страницы таба; при попытке скопировать текст — тот же комбинированный пейволл; если пользователь ранее вводил платёжные данные — предзаполненная форма; для US — дополнительные поля ZIP; авторизованным пользователям, закрывшим платёжный слой, — «ambulance» pop-up; после покупки PRO — стандартная upsell-воронка.

Точки входа (источники): кнопка «Download PDF» вверху страницы таба; закреплённая кнопка при скролле; попытка копирования текста таба; кнопка «Download PDF» на странице Print.

## Аудитория / платформа / сценарий
Платформа: Web. Аудитория: пользователи, кликнувшие download / copy / print на страницах таба (пользователи без Pro-прав). Дневные объёмы страниц (без Pro): Tab Copy — 15 532,2 unified id / 2 489 залогиненных; Tab Download — 6 487,93 / 1 313,13; Tab Print — 5 458 / 1 121,67.

## Baseline
Замер текущей воронки Export PDF (суммарно по источникам): Tab views 25 463 → landing views 5 549 (1,68%) → plans 1 740 (31,4%) → checkout views 476 (27,4%) → purchased 51 (10,7% от checkout; 0,92% от landing); charged users 30; ARPPU $82,0; revenue total $2 460. По источникам: Download — landing 3 120, purchased 33, revenue $1 476; Scroll Menu — landing 2 010, purchased 15, revenue $770; Copy — landing 567, purchased 3, revenue $160. Для сравнения соседние воронки: Official Tab (Header) — landing 2 160, revenue $492; UG Tab Tools — landing 2 129, revenue $308.
Baseline целевой метрики: ARPU $0,096 (на Tab view). Период замера baseline-воронки в документе явно не указан (`missing`; есть ссылка на еженедельную таблицу воронки).

## Денежная модель (цепочка поведение→деньги, все коэффициенты)
- Тур «съедает» ~30% пользователей (CVR tour start → tour end = 70%); 65% пользователей, входящих в воронку, доходят до тура. Отсюда: с туром гипотетически теряется 19–20% платящих; убрав тур (вариация B), можно вернуть ~$495 на весь PDF-флоу.
- Вариация C: удаление шагов от клика «download PDF» до plans сохраняет как минимум 5% отваливающихся пользователей, плюс эффект удаления тура из B; итого ожидание чуть выше B (~+5%): ~$520.
- Табличная модель A/B: Access 51 → 61 (B, +10) / 64 (C, +13); Tab View → Access 0,20% → 0,24% (+20%) / 0,25% (+25%); Charges 30 → 36 / 37; Revenue $2 460 → $2 952 (+$492) / $2 980 (+$520); ARPPU неизменен $82,0; ARPU $0,096 → $0,115 (+$0,02) / $0,117 (+$0,021).
