# HX-03 — pre-launch карточка
(без идентификаторов источника)

## Контекст и цель
Цель — увеличить выручку через механику tour update в мобильном приложении. Текущий сценарий tour update показывает обязательные (нескипаемые) splash-экраны только при обновлении приложения. Недостатки текущего решения, заявленные автором: (1) новая аудитория, установившая приложение уже после релиза версии с туром, tour update вообще не видит; (2) непропускаемые pop-up'ы фрустрируют пользователей, особенно при накоплении нескольких туров (прошлые эксперименты со скипаемым туром показали значимое падение конверсий); (3) показ tour update конкурирует и каннибализирует похожие механики (например, sales slashes). Желаемое: расширить аудиторию показа на новые инсталлы, расширить набор туров в рамках сессии, сделать обязательный показ опцией, позиционировать туры как ценный контент.

## Предлагаемое изменение (что именно меняем, для кого, где)
Добавить постоянную точку входа в tour update на экране Explorer в виде CTA-«story card» (карточки). На экране может быть только одна такая карточка. Пользователь не может скипнуть запущенный из Explorer tour update. Карточка размещается ближе к секции Collections; после прохождения тура карточка помечается «watched» и переносится в конец списка (флаг ставится только если пользователь дошёл до пейволла/success-экрана). Flow: free-пользователь → карточка → нескипаемый тур → пейволл (при покупке — алерт «All set»); premium-пользователь → тур → success-экран. Первая итерация тестирует эффективность размещения/визуала новой точки входа и её синергию с sales-баннером и другими элементами Explore. Тур — существующий «Smart Scroll» tour update.

## Аудитория / платформа / сценарий
Новые инсталлы всех пользователей, завершивших Tour Install (входной тур). Платформы: iOS и Android (считаются раздельно). Сценарий: первая и последующие сессии на экране Explorer.

## Baseline
- iOS: Tour Install End 9,315; Access 1d 335; конверсия Tour Install End → Access 1d = 3.59%; ARPPU $22.03; ARPU $0.43.
- Android: Tour Install End 10,855; Access 1d 193; конверсия 1.78%; ARPPU $25.79; ARPU $0.21.
(Горизонт объёмов в модели явно не подписан; по сопоставлению с плановой длительностью похоже на суточные объёмы — assumption.)

## Reach
Модель: 30% завершивших Tour Install увидят tour update (iOS 2,794; Android 3,256 просмотров в модельном периоде). Отдельного расчёта reach за день/период сверх этого — missing.

## Денежная модель (цепочка поведение→деньги, все коэффициенты)
Tour Install End → просмотр Tour Update (30%) → Access из Tour Update (1%): iOS +28, Android +32 дополнительных access. Итого Access Total: iOS 335→363 (3.59%→3.89%, +8.5%), Android 193→225 (1.78%→2.07%, +16%). Charges: iOS 180→195, Android 89→104. ARPPU принят неизменным ($22.03 iOS / $25.79 Android). Revenue: iOS $3,965→$4,295 (+$330), Android $2,295→$2,682 (+$387). ARPU: iOS $0.43→$0.46 (+7%), Android $0.21→$0.25 (+16%).

## Ожидаемая incremental revenue и горизонт
iOS +$330, Android +$387 на модельный период (по-видимому, в сутки — assumption, явно не указано). Ожидаемый рост ARPU: iOS +7%, Android +16%. Годовой/иной горизонт экстраполяции — missing.

## Допущения и их коэффициенты (каждое с типом)
- Текущие конверсии Tour Install End → Access 1d (3.59% / 1.78%) — observed fact.
- ARPPU ($22.03 / $25.79) — observed fact (текущее значение), неизменность в тесте — assumption.
- 30% завершивших Tour Install увидят tour update — assumption.
- 1% конверсия из просмотра Tour Update в Access — assumption.
- Итоговый рост ARPU +7% (iOS) / +16% (Android) — forecast-model (производное от допущений выше).
- «Пользователи попадут в новую воронку и смогут купить подписку там» — author opinion.
- Дополнительные accesses инкрементальны (не каннибализируют базовую конверсию) — implicit assumption, в документе не обсуждается.

## Evidence, доступный до запуска
- Прошлые эксперименты со скипаемым туром показали значимое падение конверсий (описательно, без ссылок) — основание делать тур нескипаемым.
- Референсы паттернов сторис/карточек у сторонних приложений (Snapchat, Revolut, Flo, Greatness, Uber Eats).
