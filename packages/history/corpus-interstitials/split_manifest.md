## Правило (зафиксировано до открытия outcomes)

1. Единица корпуса — Confluence-страница проекта (итерации внутри страницы — один кейс).
2. Пригодные уникальные эксперименты (10 шт., см. `corpus_eligibility.md`) отсортированы по дате запуска страницы (возрастание).
3. Размер holdout задан формулой, зафиксированной до подсчёта: N ≥ 12 → 5; 9 ≤ N ≤ 11 → 4; 6 ≤ N ≤ 8 → 3. N = 10 → **holdout = 4 наиболее поздних**.
4. **Cutoff date: 2026-01-01** — дата запуска ≥ cutoff → holdout; < cutoff → knowledge-source set. (Фактический зазор между соседними кейсами: 2025-08-20 … 2026-03-09.)
5. Выбор не зависит от успешности экспериментов: величины результатов на момент фиксации не читались; сортировка и размер — чисто временны́е.
