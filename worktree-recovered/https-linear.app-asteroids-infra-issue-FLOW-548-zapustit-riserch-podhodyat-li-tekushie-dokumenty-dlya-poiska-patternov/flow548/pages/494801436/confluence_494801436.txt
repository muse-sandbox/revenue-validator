# Hypothesis

If we increase prices to MU level of books subscriptions, we'll see an extra $N in revenue

# A/B test plan

Base value of the metric (ARPU) $0.19

Lift, % 130%

Minimal detectable effect 0.0224

Probability of true-positive (power) 0.8

Probability of false-positive (p-value) 0.05

Sample size (for all the variations) 30

How many days it'll take to conduct the test 64740

# Description of the Solution & Mockups

### Solution

We'll test 2 prices tiers

A - Annual (7 days trial) - $59.99 /  Monthly - $19.99

B - Annual (7 days trial) - $149.99 / Weekly - $19.99 Brainthree doesn't offer the option to create a weekly plan; the minimum period available is a month.

B - Annual (7 days trial) - $149.99 / Monthly - $29.99 (discount 60%)
