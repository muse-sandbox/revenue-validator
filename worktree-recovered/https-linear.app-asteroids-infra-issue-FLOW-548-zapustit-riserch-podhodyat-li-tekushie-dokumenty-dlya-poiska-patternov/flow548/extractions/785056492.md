## RESULTS
(Эксперимент #7502, exposure event: App Experiment Start; период 2026-05-27 — 2026-06-08, 12 дней; выборки control 18 928 / var2 18 600 / var3 10 742, var3 остановлена 2026-06-03.)
- Факт по target metric (с значимостью): CR members → subscribers: Var B (3 мес) −4.76% (p=0.28, незначимо), Var C (6 мес) −11.08% (p=0.028, значимо); CR members → buyers: B −8.98% (p=0.07), C −11.90% (p=0.038, значимо). Заявленная в дизайне метрика «landing plans view → subscribed» в результатах напрямую не показана — считались members→subscribers по exposure App Experiment Start | Results → Significance analysis, Monetization Metrics.
- Факт по guardrails: retention web 1d/7d/14d: B −2.1%/−1.6%/−0.95% (незначимо); C +21.3%/+17.0%/+15.8% (p=0.000) — но var3 остановлена в середине эксперимента, значимый «плюс» ретеншена и tab view (+23–28%, p=0.000) — артефакт состава остановленной группы, документ это не комментирует; churn 14d, refund 14d — незначимо (refund 14d +33.3% B / +40.1% C, незрелые) | Results.
- Денежный результат ($ или %, значим ли): отрицательный, незначимый: ARPU B −7.07% (p=0.23), C −10.84% (p=0.11); Revenue факт: control $28,987 vs B $26,472 vs C $14,668 (var3 — вдвое меньшая экспозиция); post-forecast per day: B −$918/день, C −$1,408/день | Results → Significance analysis, Forecast (per day), Stats.
- Rollout-решение: Do not roll out | Results → Decision.
- Post-rollout incremental revenue: раскатки не было — n/a; 2-летняя оценка (Insights → Forecast Revenue): control $48,057 vs B $47,436 vs C $26,152 estimated revenue | Insights.
- Каннибализация/refunds (факт): сильная субституция: instant accesses 627 (control) → 470 (B) → 282 (C); доля instant-типов 21.3% → 9.5% / 11.4%; новые 3/6-месячные планы (88 и 56 accesses) закрыли только часть потерянного instant-объёма; trials выросли +22.7% (B) / +12.2% (C); refund 14d +33–40%, незначимо, окно не созрело | Results; Insights.
- Расхождение plan/fact (ожидали vs получили — числа): ожидали Subscribed +14.06% (B) / +7.02% (C) и Revenue +4.97% / +5.39% — получили subscribers −4.76% / −11.08% и revenue-тренд −7…−11%; ожидали trial −10%/−8% — фактически trials share +22.7%/+12.2% (знак противоположный); допущение «instant полностью перетечёт в новые планы» не сбылось | Reach & Impact vs Results.
- Какие допущения подтвердились/нет: НЕ подтвердились: перетекание instant→3/6-мес (планы оказались субститутами, а не дополнением), снижение trials; частично: upsell почти без изменений (+2% B / +1.5% C — по метрикам близко к нулю). Подтвердилось: ambulance/comeback/month стабильны | Results; Insights.
- Сегменты (что показали): сегментных разрезов (по гео/трафику/платности) нет; есть разрез по типам планов (plans distribution) — см. каннибализацию | Insights.
- Insights: гипотеза «дешёвый короткий план снимет ценовой барьер» не подтвердилась — годовой instant план был не барьером, а предпочтительным форматом коммитмента высокоинтентных пользователей; его удаление сократило immediate-payment конверсии, а не открыло новую платящую аудиторию; позитивная trial-механика (+22–26% trial share, +22–26% trial→charge) не компенсирует потерю instant annual выручки | Results → Decision; Insights.
- Следующие итерации: (1) перепроверить churn/refund через ~2 недели, когда созреет окно 14d charges (Pending: B 24.0%, C 15.7%); (2) проверить anchor-эффект — оставить instant annual рядом с 3-месячным планом; (3) считать annual instant план ключевым конверсионным драйвером web и защищать его в будущих итерациях пейволла | Results → Next steps.
