## RESULTS
- Факт по target metric (с значимостью): It.1: 0.13% vs 1.5% target — FAILED (-91.59% к плановому уровню). It.2: 0.19% (74 user) у варианта B; watch-ad CTR у C 2.77% (1,103 users). It.3: 1.03% vs 1.5% (в Conclusion — «click-through rate from DAU 1.16% vs 1.5%»). Формальная значимость по целевой метрике (p-value) не приведена; в it.1 значимость заявлена только для каннибализации («statistically significant for both metrics»).
- Факт по guardrails: каннибализация. It.1: install click -45.25%, app installs -54.40% (стат. значимо). It.2: B — -45% install clicks, -57% installs, -29% fact revenue; C — -35% clicks, -43% installs, -25% revenue. It.3: (при исключении установок после fakedoor) installs -41.56%, in-app charged revenue -34.29%.
- Денежный результат ($ или %, значим ли): отрицательный во всех итерациях. It.2: total revenue (est.) B -26.87%, C -24.86%; при исключении fakedoor-инсталлов B -42.68%, C -52.43%. It.3: total revenue (est., без fakedoor-инсталлов) -5.74% ($1,155 vs $1,225 за период); Forecast per day: $6,821 vs $7,221 = -5.55%. Важно: вся «microtransaction revenue» в Results — оценка через допущенные 45% click→charge (fakedoor, реальных платежей не было): it.2 $32.97, it.3 $349.72. Значимость денежного результата не тестировалась.
- Rollout-решение: раскатки нет. It.1 FAILED, It.2 FAILED, It.3 FAILED; «closing this iteration and the project as a whole as FAILED».
- Post-rollout incremental revenue: missing (раскатки не было; секции «Post-rollout analysis» пусты).
- Каннибализация/refunds (факт): каннибализация — подтверждена и измерена (см. guardrails; вплоть до -54…-57% installs в it.1–2, -42% в it.3). Refunds — missing.
- Расхождение plan/fact (ожидали vs получили — числа): клики по микротранзакции: план 1.5–2% от splash view → факт 0.13% (it.1), 0.19% (it.2), 1.03% (it.3). Конверсия click→purchase 45% — не проверена (fakedoor), применена как допущение к факту. Деньги: план +30…+66.55% total revenue → факт от -5.55% (it.3, лучший) до -52.96% (it.2 C). Каннибализация: план -20% installs (Sc.2) → факт -42…-57%.
- Какие допущения подтвердились/нет: не подтвердились. It.1: «The coefficients used in the model turned out to be much higher than the actual values». It.3: «we are much closer to the coefficients specified in the model, but the model still does not converge». Допущение 45% click→charge так и осталось непроверенным.
- Сегменты (что показали): результаты только по общей не-Азия аудитории; разрезов по гео/ОС в Results нет | missing.
- Insights: (1) кликающие по микротранзакции сильно пересекаются с потенциальными установщиками — механизм каннибализирует installs и in-app revenue, а не добавляет новую монетизацию; (2) «watch ad» кликается лучше ($ CTR 2.77% vs 0.19%), но экономика ещё хуже (~$0.01 за клик по CPM) — ветку закрыли; (3) максимальная экспозиция (незакрываемый баннер, it.3) поднимает CTR до 1.03%, но модель всё равно не сходится.
- Следующие итерации: качественный рисерч mobweb-аудитории через пользовательские интервью для новых идей по микротранзакциям.
