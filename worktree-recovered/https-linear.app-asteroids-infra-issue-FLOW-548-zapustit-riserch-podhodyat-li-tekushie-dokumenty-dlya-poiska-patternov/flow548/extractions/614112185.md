- Сегменты (что показали): iOS-баннер по CTR работает в ~5 раз лучше Android (30% vs 7–8%); при этом на Android view→charge выше в B (6.45%); аномалия — большая разница banner charges между B и C, которая «doesn't look correct» | разделы: Metrics, Decision.
- Insights: (1) видимость баннера ниже ожидаемой: показов меньше, чем визитов страницы с нужными параметрами; (2) серьёзные data-quality проблемы: события Expiration Warning есть в ug_rt_events_app, но отсутствуют/некорректны в ug_subscriptions_events (неверный funnel_source, лишние charged/subscribed/crossgrade со старым funnel_source, нет события Autorenew Enabled), расхождение событий с нотификациями subscription_ios_notification; (3) для будущих экспериментов надо чинить структуру событий | раздел: Data issues / questions.
- Следующие итерации: явного плана следующей итерации нет; только требование корректно добавить события (ug_subscriptions_events, Autorenew Enabled, проверка Expiration Warning) «для следующих экспериментов» | раздел: Data issues / questions.
