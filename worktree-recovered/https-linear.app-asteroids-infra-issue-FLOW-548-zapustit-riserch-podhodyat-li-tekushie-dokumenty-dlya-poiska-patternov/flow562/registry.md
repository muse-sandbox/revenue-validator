Нейтральные ID присвоены по возрастанию pageId среди отобранных восьми (HX-01…HX-08), без связи с категорией.

По правилу 5b (ascending pageId) первым идёт 551514048, но его surface (upsell/cross-sell Web) совпадает с уже использованным в FLOW-548 кейсом Songbook upsell 551505371 — итерации одной программы апсейлов; для чистоты holdout применено правило 2 по духу (родственная механика той же команды в тот же период). Выбраны 699808669, 699821637, 773653380. Это отступление зафиксировано здесь явно как единственное ручное решение; 551514048 — кандидат на замену при несогласии.

## Качество и ограничения выборки

- **Нет чистого App-positive**: все явные денежные успехи вне 12 использованных кейсов — Web/CRM. App представлен в holdout только negative/ambiguous слотами (551496203, 494820283). Это отражает реальный состав корпуса, не выбор.
- Категории предварительные — финальная классификация (`positive / negative / no meaningful uplift / inconclusive / not measurable`) выполняется в ground truth независимо от текстов итоговых статусов; квоты 3/3/2 могут по итогам сместиться (это допустимо и будет зафиксировано).
- CRM-эксперимент 773653380 — email-кампания (сплит по получателям), а не продуктовый A/B в `ab_experiment`; реестровых lifecycle-фактов для него может не быть.
- Двое из negative — ns-документы: их финальный лейбл может оказаться `inconclusive`, а не `no meaningful uplift` (широкие CI). Резервные кандидаты этой категории: 614119648, 614121936, 707153996.
