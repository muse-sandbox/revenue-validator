# Research and Context

Project goal : by adapting the tour to the segmented audience, we aim to increase revenue

Foundation : split the tour into two segments: learners and players. For the former, provide the full version of the tour with all educational screens. For the latter, show a shorter version of the tour, excluding all questions about development, tips, etc.

# Hypothesis

If we segment the audience in the tour and show a shortened version to those who don't want to learn, we will increase conversion by 10%, because we will show each audience only the questions relevant to them.
