Research and Context

  • Goals: optimize the payment funnel to generate additional profit through this improvement
  • Foundation:
    • Currently, all web sources lead to a landing page, followed by a tour, paywall, and checkout. We’ve never attempted to optimize this funnel
    • The idea is to reduce the number of steps in the funnel for the “Download PDF” source
    • If successful, consider optimizing the funnel as a whole

For tour removal: tour funnel takes approximately 30% of users (CVR tour start → tour end = 70%). 65% of the users entering this funnel are those who get to the tour. That means that with the tour we could hypothetically lose 19-20% of paid users, which could give us ~495$ for total PDF flow.

As for C version: we can assume that deleting the steps from "download PDF" button click to plans can save at least 5% of the users who dropped off, + we delete the tour, respectively, we can also add a percentage from option B. So we could expect higher revenue for option C, but not so much: ~5%, so 520$

Description of the Solution & Mockups

Iteration 1

Solution

We are trying to optimize the funnel from both sides: slightly and maximally.

B: we keep all elements of the existing funnel unchanged

  • however, we remove the tour 
  • place the modal windows directly in the context of the tab page

C: We streamline the user flow from the source to the payment layer:

  • after clicking the source, direct users to regwall
  • then direct users to a universal payment layer that includes plan selection, and payment details
  • сlose all three sources with a new upgrade modal, including attaching the modal to the Print button at the bottom of the tab page
    • when trying to copy the text, we also show a combined paywall
  • if the user previously entered payment details — show a pre-filled form
  • for the US, display additional ZIP code fields
  • for authorized users who close the payment layer, show an ambulance pop-up
  • after purchasing PRO, the user is directed to the standard upsell funnel
