Research and Context

  • Goals

    • increase revenue by selling features available in the app

    • promote the app to the part of the audience that only has accounts on the web
  • Foundation:

    • tour updates in the app are a common practice and a source of additional revenue

    • the app releases interesting features that web users might not know about, the idea of the project is to inform users about these features while also trying to sell them within the app
    • we will sequentially test several tour update options using Practice Mode as an example
      • in the first iteration, we check the button’s CR on the tab page. When clicking the button, a modal window will appear, explaining the feature and showing a QR code to redirect to the app
      • in the second iteration, we will try launching the tour upon visiting the 2nd page in a session. In this iteration, we will attempt to sell accesses directly on the web (feature tour → sale → redirect to the app)
      • we might also consider a combined approach for greater audience engagement in the tour update

Solution

Try launching the tour upon visiting the 2nd page in a session. In this iteration, we will attempt to sell accesses directly on the web (feature tour → sale → redirect to the app)

  • When users visit the second page on the web, display a modal window presenting an update tour

    • when visiting the second page on the web, a modal window is displayed with an update tour that explains the new feature in the app

    • after describing the features, we display a checkout for purchasing access

    • we sell trial PRO access along with access to Practice Mode in the app for $99.99 at checkout

    • after the purchase, we show a success screen, informing the user that they need to download the app to use the feature

  • Base iteration on the styles and copywriting from the project with the app’s update tour

  • If the user doesn’t transition to the app, they will still have full access to the Pro features on the web

Decision

Results

Conclusions Redfail

  • Didn't get the expected increase in subscription sales
  • Has no any effect since very small amount of users who notices and interested in new feature (only ~60% got to the last preview window (PlayBack Hook View)) and less than 1% of those clicked purchase
  • Trial → charge conversion decreased on 42%, but it's still not representative because of the small number of charges (21 vs 14) and due to the fact that we could not effect this
  • Closing the iteration as a fail
  • In this iteration I will close the series of experiments with the tour update on the web
