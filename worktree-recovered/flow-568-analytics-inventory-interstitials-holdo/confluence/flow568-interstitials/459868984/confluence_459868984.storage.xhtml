Description of the Solution & Mockups

Solution

  • When we get no-fill state (ex HL-ad), we instantly change it to landing
  • Applies only for iOS
  • This offer available only for users without any current subscription or active trial.
  • The close button appears immediately for this launch.
  • The logic of showing the landing
    • User goes to tab
    • There is a trigger for showing interstitial 
    • Interstitial conditions:
      • We show it only 5 times per day. With 180 sec gap in between these cases.
      • The logic renews everyday at 23:59
    • Conditions to perform:
      • If "no-fill" state wins: we show Landing (close button is instant). Then we make a note that we shown it today
      • If any kind of ad won: we show winner's ad
      • If "no-fill" state wins again: we DO NOT show it this day again. And just let user pass to the tab. 
    • That means:
      • We show landing once per day
      • Only for the first "winning of no-fill state"
      • Mute landing until the rest of the day
      • And then show again on next day with the same logic.
  • The landing:
    • Landing is scrollable 
    • It has button which scroll landing to the paywall in the bottom of the screen



  • We show it instead of interstitial
    • Close button is available instantly
