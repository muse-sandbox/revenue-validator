# Research and Context

Project goal: Add interstitial in direct sales on Artists

# Release Goal

Introduce the ability to show interstitials before tabs of specific artists.

# Description of the Solution

The idea is to show interstitials on specific artists, the result of whether to show will be received from the backend

# A/B

https://www.ultimate-guitar.com/components/ab/experiment/view?id=4716

### API Requirements

#### Functionality:

В ответ запроса " ads/config ", добавить поле artistsForDirectSales = [], где в случае если нужно сделать предзагрузку интерстишл возвращать список id артистов

Результат ответа будет зависеть от геопозиции, времени и продолжительности, следовательно нужна какая-то админка, где можно будет динамически изменять и дополнять информацию о показе прямых продаж на интерстишелах

Пример: Я захожу в админку, выбираю количество стран, старт и финиш показа прямых продаж, Музыкантов и Страны, где нужно будет показывать прямые продажи.

UPD пример: заходим в админку и выбираем только артистов, на которых показываем интерстишелы, все остальные настройки делаем через GAM

Музыканты: AC/DC, Metallica
