# Description of the Solution & Mockups

## Iteration 1

### Solution

Figma

We change the banners and interstitial with the inner banner selling access to UG Pro+

Apply plan Pro+ $39.99 / year with extended trial period (14 days)

new products for 14-day trial

ios : com.ultimateguitar.ugt.plus.1year7

android: com.ultimateguitar.tabs.plus.1year5

We change interstitial and banners everytime when:

User enters the screen with ad-source and don't get and ad to see

They get adfail event (уточнить ивент)

If there is no response on the ad to show → show inner

For banners also, if we see no ad OR zero-state (ad of Melodics) → change to new banners

We put the visuals inside the existing sources

After clicking on the banner or interstitial → show paywall with 'Go ad-free experience'

Apply logic only for free users without any subscriptions (exclude Edu and Sings singles)

after 5 second on interstitial → show close button

Current interstitial logic:

User enters the tab and at that time we check their data about last visit.

Interstitial conditions:

We show it only 5 times per day. With 180 sec gap in between these cases.

The logic renews everyday at 23:59

so there might be 2 cases:

we got the ad → shown to a user →  stored the last show time 

the as is not loaded → we got ad_load_failed event (this cycle is constantly processed at Android) → no additional actions, we try next time

then we repeat those steps until we meet the limitations above (5 times per day)

The cycle looks like:

no watcher marker → show ad → store marker → repeat 

at Android the server tries to show ad, but can not, due to it has no ad to show
