# Research and Context

Now that AppLovin is almost a monopolist in-app advertising we can not afford not to add them to our stack. As the Ad Ops Manager I want to maximize our revenue from our in-app interstitials by implementing the mediation platform from Applovin MAX. This will bring us extra $1000/day, because of additional demand and competition. 

We want to implement AppLovin MAX mediation for interstitial ads to:

Increase competition (more bidders)

Improve eCPM and fill rate

Target +$1,000/day incremental revenue

# Hypothesis

If we use the Applovin MAX platform to mediate the interstitials in the UG app we'll earn extra $1000/day because of additional demand and competition.

## Experiment design template

[macro]
Integration plan
### Phase 1 — Preparation & Audit (2–3 days)

### 1. Current Stack Assessment

Map current interstitial setup:

Networks (AdMob, Unity Ads, ironSource, etc.)

Waterfall structure

eCPM by geo/platform

Identify:

Fill rate gaps

Low-performing geos

Latency issues

### Phase 2 — MAX SDK Integration (3–5 days)

### 1. SDK Integration

Add AppLovin MAX SDK (iOS + Android)

Ensure:

Latest SDK version

SKAdNetwork IDs configured (iOS)

GDPR/ATT consent flow integrated

### 2. Ad Unit Setup

Create Interstitial Ad Units in MAX dashboard

Separate by:

Platform (iOS / Android)

Potentially by geo tier (optional for scaling)

### Phase 3 — Demand Integration (5–7 days)

### 1. Add Core Networks in MAX

Prioritize high-performing bidders:

Google AdMob

Meta Audience Network

Unity Ads

ironSource

Mintegral

Pangle

👉 Enable bidding (header bidding) wherever supported
👉 Use waterfall only as fallback

### Phase 4 — Testing & QA (3–5 days)

### Functional Testing

Ad load success rate

No crashes / ANRs

Frequency capping works

Correct triggers (e.g., after song views, navigation points)

### Revenue Validation

Compare:

MAX vs current mediation (A/B test if possible)

Validate:

eCPM uplift

Fill improvements

### Phase 5 — A/B Experiment (7–14 days)

### Setup

Split users:

Control: Current mediation

Test: MAX mediation

### Measure

ARPDAU (primary KPI)

Interstitial impressions per DAU

eCPM

Retention impact (very important)

### Decision Rule

Rollout if:

≥ +10–15% ARPDAU uplift

No significant retention drop
