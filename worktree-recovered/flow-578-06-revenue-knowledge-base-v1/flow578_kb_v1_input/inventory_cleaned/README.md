## Как фильтровать и сравнивать (правила из FLOW-574)

1. **Гейт валидности (блок A):** кейсы с `result_class: inconclusive` и кейсы
   с загрязнёнными величинами (T2-06 — баг таргетинга; T1-02 iter1) не являются
   основанием продуктового вывода — только measurement-уроками.
2. **Уровень близости** нового кейса к историческому считается по осям блока B
   (`exact / adjacent / different` — §2–3 модели): L1 требует mechanism + flow_stage
   exact и сопоставимого сегмента; совпадение только по `metric` (тип 3) даёт L3 —
   baseline, дисперсию, guardrails и ловушки измерения, но не продуктовый вывод.
3. **Переносится всегда только знак и механизм**; величины эффектов из
   `plan_fact`/`ci` — только как prior для sizing с явной пометкой.
4. `source_confidence: verified-card` теперь у **всех 24 кейсов**: 14 кейсов типов
   2–3 сверены со страницами Confluence 2026-08-04 (снапшоты в
   `output/confluence/flow577_verify/`), p-values извлечены в поле `ci`, гейт §4.6
   модели FLOW-574 применим ко всему корпусу без L3-ограничения. Найденные при
   сверке систематические ошибки зеркала: даты запуска почти везде расходились со
   страницами; пропущенные AB id (7268, 7502, 6614); класс significant-*
   назначался там, где страница фиксирует незначимость целевой метрики или значимые
   guardrail-негативы.
5. `result_class: mixed` — расширение словаря модели V0 (разные исходы по
   платформам/рукам). Предложение для модели V0.1: hard filter применяется к той
   платформе/руке, чей вывод переносится (см. шапку `inventory.yaml`).

## Кросс-корпусные наблюдения (интерпретации, не факты)

- **Instant вместо trial** подтверждён в трёх разных flow: интерстишл ex-paid
  (T1-08), интерстишл free iOS (T1-10, surface-чтение), внутренние пейволлы iOS
  (T3-06) — с одинаковой ценой риска (LTV/renewal дискаунт-когорты) и одинаковым
  And-ограничением эластичности (T1-10, T3-01).
- **CTR/attention ≠ intent** повторяется на трёх поверхностях: T1-09 (paywall→click
  (нескипаемость ×8 вовлечение при retention-цене).
- **Лишний шаг воронки = мультипликативный drop-off**: T1-03 (96% на pre-paywall),
  T2-07 (демо-пауза −36% access CR).
  планов ломают баланс якорей.
