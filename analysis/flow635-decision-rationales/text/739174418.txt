# Research and Context
Goal: Increase conversion to subscription and trial uptake in the UG app by letting users briefly experience selected premium features (e.g. Autoscroll, Smartscroll) before showing the paywall. We are doing this now because we see that direct, upfront paywalls on feature tap block users from understanding the value of these features, which likely suppresses both perceived value and willingness to start a trial/subscribe.
Foundation: Right now, when a user taps a premium feature, we immediately show a paywall, and the feature is available only after purchase or trial start. With the change, the user will be able to use the premium feature for about 10 seconds after tapping it, and only then see the paywall. The problem today is that we ask for payment before demonstrating value, so users cannot try the feature, undervalue the subscription, and are less likely to convert.

### Research results
When to Use Interactive Demos vs. Free Trial or Freemium Plans
Many free users don't even start the trial: they are hindered by a “fatal” step (fear of forgetting to cancel, possibly needing an account/card, psychological barrier). But the demo allows them to see the feature without any barriers — more people will see the value and then agree to a trial or purchase.
We removed the free trial and conversions went up — here’s how
Reddit: removed the trial period, left 3–5 feature activations — conversion increased, free users were more active in switching to paid plans
How Interactive Demos Increase Demo Requests?
SmartCue: Demo interaction before purchase/trial shortens the cycle and increases the chance of conversion, especially among “lazy” users.
The Ultimate Guide to Using ‘Request a Demo’ to Boost Conversion Rates
A brief complimentary experience (even 5–10 seconds) increases engagement and conversion in later stages because it breaks down mistrust without requiring a long-term commitment.

# Hypothesis
If we implement a 10-second premium feature demo for free users (and ex-subscibers) when they tap a locked feature, we expect the trial start rate to increase by at least ХХ% without drop in 7-day retention because the instant hands-on experience will lower psychological friction and better showcase feature value. The significance level is set at 95%.

# Description of the Solution & Mockups
  [param title] 1 iteration

### Solution
#6806
Only free users participate in the experiment (no subscription and never had one).
Participants can use the following features:
autoscroll
smartscroll
transpose
simplify
official tab
After using one of the functions from the list above, a 10-second countdown begins. After this time, a paywall widget appears, displaying information about the function used and a call to purchase a subscription.
The project allows the user to access the official tab.
In this case, the paywall should be displayed to the user after 10 seconds of being on the official tab
Or when clicking any button on the official tab
We do not allow the user to use the functionality of the official tab or navigate from it to deeper screens (comments, artist, etc.).
If the user activates several functions within these 10 seconds, we display the paywall from the first timer that triggered, but the use of the other functions is also terminated.

Conclusion
Do not roll out.
